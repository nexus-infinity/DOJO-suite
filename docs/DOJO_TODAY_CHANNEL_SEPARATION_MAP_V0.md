## Processing seam explicitly held for the next phase

The existing code now exposes a typed processing contract, but it does not yet have a
runtime producer or Today experience consumer for one complete processing result
containing all of the following as separate fields:

```text
current object
intention
intended sequence
minimum steps
evaluation question
unresolved decision
evidence state
HOLD / Unknown
Arkadaş continuity and disagreement state
```

The contract is `TodayProcessingPacket`. Its `HOLD` / `Unknown` values and
`mayProjectResolvedState` guard preserve the processing boundary. The next
functionality pass must add only a lawful producer/consumer if its source and
evidence are available; it must not become a `Current Evaluation` card or silently
change authority.

## Mirror-portal identity boundary

`DOJO Suite` is the sacred-geometry genotype expressed as a working phenotype: a
mirror portal into the `◼︎ DOJO` spinning top. DOJO and SOMA may carry the same
pulse genotype, but `SOMA` is a distinct sovereign phenotype and home. SOMA is
not a synonym for the Suite, a replacement model route, or a decorative label.
Both are co-present FIELD phenotype lanes; a specific live relationship or route
between them remains `Unknown` / `HOLD` until processing supplies witnessed
evidence. The surface may present a DOJO portal state and acknowledge SOMA as a
separate peer, but it does not manufacture SOMA state or promote either identity
to authority.
