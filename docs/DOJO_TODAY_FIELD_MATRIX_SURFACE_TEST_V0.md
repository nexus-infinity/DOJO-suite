
```text

```

```text

```

Resonance is measured response, not decorative harmony. Excessive repetition, contrast, motion, sound, or persistence is uncontrolled amplification.

## Surface decisions — design direction, not runtime implementation

### 1. Allocate by reciprocal material, not permanent panel entitlement

```text
no selected object + no prepared digital object
→ right utility defaults quiet/collapsed or reduced to its mode strip

selected object or prepared digital proposal
→ relevant utility may dock if capacity permits

verification or Focus Lease
→ only required comparison context remains present
```

The right utility remains a stable semantic object even when its visible form changes.

### 2. Give the centre an explicit relational state

The centre must distinguish:

```text
READY_FOR_ORGANIC_INTENTION
DIGITAL_OBJECT_PREPARED
SHARED_OBJECT_ACTIVE
AWAITING_HUMAN_AUTHORITY
HOLD_WITH_RECHECK
RETURNING_TO_PRIOR_WORK
```

These labels are contract states. Ordinary UI copy remains calm and human-readable.

### 3. Keep the composer primary while reducing machinery pressure

- Preserve text, voice, attachment, mode, provider/model, and submit as separate functions.
- Allow provider/model machinery to compress behind one declared control when width or attention capacity is insufficient.
- Never conceal the active provider/model when consequence requires it.
- Keep non-wired voice and attachment visually distinct from available actions.

### 4. Use capacity-derived surface states

Breakpoints are triggered when the current relationship can no longer be expressed without violating readable measure, target size, object identity, attention hierarchy, or accessibility—not from device name alone.

Candidate states for controlled testing:

| State | Capacity posture | Left | Centre | Right | Composer |
|---|---|---|---|---|---|
| Expansive | Both rails and readable centre fit | Expanded | Dominant | Contextually expanded | Full controls |
| Working | One auxiliary region must yield | Expanded or compact | Dominant | Contextual/collapsed | Provider controls compressible |
| Compact | Centre and composer require priority | Compact/destination | Dominant | Destination/overlay | Intent first; machinery disclosed |
| Focus | One declared object claims bounded attention | Quiet | Single object | Required comparison only | Bounded action controls |

Pixel thresholds remain `HOLD.MeasurementRequired` until rendered specimens prove them.
